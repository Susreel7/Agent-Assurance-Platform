# Agent action governance — design set

This folder is the reviewable design for the product. It is written to be read in order,
argued with, and then executed one phase at a time. **No code is written from this folder
until the phase gate before it has been demonstrated.**

The existing `agent-assurance` implementation is treated as *prior art and a migration
source*, not as a constraint. Where the current code contradicts this design, this design
wins and [`10-migration.md`](10-migration.md) says how we get from one to the other.

> (D-08 … D-18) in [`17-research-conclusions.md`](17-research-conclusions.md) §6 with its old
> assumption, evidence and migration implications. Nothing was silently rewritten. Start at
> [`17`](17-research-conclusions.md) if you have read this folder before.

## One sentence

An enterprise cannot say what its AI agents actually did, under whose authority, or whether
the destructive one could have been stopped. This product answers those questions across
every AI client the enterprise runs — and is honest about what it cannot see.

The unit of governance is the **AI action**: `⟨subject, capability, resource, context,
decision, evidence⟩`. A model request is one kind. A shell command is another.

## Principles this design is held to

1. **Enforcement is graded, and the grade is published.** Every control is **A** mediated ·
   **B** interposed · **C** attested · **D** observed · **E** dark. We never present a Grade B
   control as a Grade A one, and we always show the size of the Grade E population.
   *(Revised by D-09. The previous wording — "enforcement is server side" — was true of MCP
   and false of the agent's shell, which is where the incidents happen.)*
2. **The control plane is never on the request path.** A control-plane outage must not open
   access and must not stop work. The data plane runs the last signed policy bundle.
3. **Payloads stay in the customer boundary.** The control plane stores counts, digests,
   facets, decisions and reason codes — enforced by the event schema, not by discipline.
   Reading a prompt is a separate permission plus an audited approval.
4. **The credential is the control.** A short-lived, audience-bound, task-scoped credential
   prevents what no amount of prompt inspection can. *(D-10.)*
5. **Every decision explains itself.** Same reason code and same sentence in the API error,
   the console and the audit row — plus the enforcement grade it was applied at.
6. **Absence beats denial.** A tool you may not call is not listed; a module you may not use
   is not in your navigation.
7. **Onboarding is three screens or it fails commercially.** If configuring us is hard, the
   feedback is "we don't need this tool", regardless of how good the enforcement is.
8. **We never claim proof we do not have.** Residency is *attested from endpoint
   configuration and contract*, not geolocated. DLP *reduces* risk; it does not prove
   absence. **We cannot prevent prompt injection.** All three are stated in the product UI.
9. **Discovery is always free and never blocks.** A registration wall that developers route
   around turns a governance product into shadow AI's best recruiter. *(D-17.)*
10. **Cardinality and cost are integers.** Money is `cost_micros`. Dashboard dimensions are
    enumerable. Free-form text is never a rollup dimension.

## Vocabulary

| Term | Meaning |
|---|---|
| **account** | One customer tenant |
| **org unit** | A node in the customer's tree: business unit, department, team, or distribution list. One table, one closure. |
| **member** | A person. Has zero or more `member_identities` (one per IdP subject). |
| **service identity** | A non-human caller that is not an agent. May never be the root of an action chain. |
| **agent** | A registered AI client or autonomous agent |
| **agent version** | The unit that gets **approved**. A changed agent is a new agent until a human says otherwise. |
| **agent instance** | One running copy, on one host, in one environment |
| **session** | One continuous context window. Carries **taint**. |
| **capability** | A typed, versioned thing an agent can invoke: `mcp.tool`, `shell.exec`, `net.http`, `fs.read`, `vcs.write`, `cloud.api`, `agent.delegate`, `memory.write` … |
| **AI action** | One capability invocation with its identity chain, resource, decision and evidence |
| **enforcement grade** | A · B · C · D · E. Mandatory on every decision. |
| **taint** | `clean` · `tainted` · `tainted_with_secrets`. Rises when a session ingests untrusted content. |
| **credential lease** | A short-lived, audience-bound, scoped credential issued for one task |
| **grant** | (subject, capability selector, scope, environment, max taint, expiry) |
| **decision** | `allow` · `annotate` · `mask` · `tokenize` · `route_internal` · `require_approval` · `step_up_auth` · `rate_limit` · `quarantine` · `deny` |
| **alias** | A stable model name we publish, bound to one or more provider endpoints |
| **endpoint** | A concrete provider URL with a known region, zone and residency class |
